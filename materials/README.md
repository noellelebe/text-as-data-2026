# Course materials

See the [course README](../README.md) for installation and instructions for running the notebooks.

- `notebooks/` contains the practical sessions and exercises.
- `data/` contains the bundled CSV files and a [guide to their sources](data/README.md).
- `requirements.txt` installs the core Python packages.
- `requirements-transformers.txt` installs the additional transformer packages and includes the core requirements.
- `environment.yml` and `environment-transformers.yml` provide conda alternatives.
- `scripts/download_open_datasets.py` is an optional script for rebuilding selected datasets; it is not needed for class.
