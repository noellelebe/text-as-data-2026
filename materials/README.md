# Course materials

Start with the [course guide](../README.md) for installation and the recommended order of work.

- `notebooks/day_1_representation.ipynb` — guided Day 1 example.
- `notebooks/day_1_representation_exercise.ipynb` — student exercise.
- `data/` — bundled CSV files and [dataset sources](data/README.md).
- `requirements.txt` — base Python packages.
- `requirements-transformers.txt` — optional transformer packages; includes the base requirements.
- `environment.yml` and `environment-transformers.yml` — conda alternatives.
- `scripts/download_open_datasets.py` — optional dataset rebuild script; not needed for class.

The instructor solution notebook is kept locally and excluded from the student repository.
