# Day 1 slides

[`main.pdf`](main.pdf) is the Day 1 slide deck. [`main.tex`](main.tex) is its editable Beamer source; the `assets/` and `figures/` folders contain images used by the slides.

Students can read the PDF without installing LaTeX. To rebuild it, open a terminal in this folder and run:

```bash
pdflatex main.tex
pdflatex main.tex
```

The practical work is in [`../materials/notebooks/`](../materials/notebooks/). Start with `day_1_representation.ipynb`, then complete `day_1_representation_exercise.ipynb`.
